Cifra de César em C

Um projeto simples em C para praticar lógica de programação usando a Cifra de César.

O programa recebe uma palavra e uma chave e desloca as letras pelo alfabeto.

casa + 3 = fdvd


pratiquei

* Arrays
* Strings
* Loops
* if
* fgets() e scanf()
* Operador %
* Lógica de programação

Como executar:

bash
gcc cifra.c -o cifra
./cifra
